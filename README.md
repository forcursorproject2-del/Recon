# Core Parser: Система Парсинга Финансовых Документов (Версия 2.1)

## Описание

Core Parser — это полнофункциональная многофейзовая система для автоматического парсинга финансовых документов в формате PDF. Основная цель — автоматизация бухгалтерского учета предпринимателей с возможностью коммерциализации как SaaS или API.

Система включает:
- Извлечение текста из PDF с поддержкой различных библиотек и fallback-логикой.
- Классификацию документов по 6 типам с использованием ансамбля методов (правила, ML, частично BERT).
- Семантический анализ полей и нормализацию таблиц.
- Пакетную многопоточную обработку больших объемов документов.
- Высокоэффективное активное обучение с обратной связью для повышения качества.
- Оптимизированное кэширование OCR-результатов для повышения скорости.
- Удобный Eel веб-интерфейс для управления процессом и просмотра результатов.
- Интеллектуальную валидацию данных и автоматику исправлений.
- Гибкую YAML-конфигурацию для паттернов и сигнатур.

## Основные возможности

- Поддержка извлечения текста через pdfplumber, PyMuPDF с использованием EasyOCR при необходимости.
- Классификация на 6 типов: invoice, payment_order, act, invoice_factura, reconciliation_act, dismissal_act.
- Семантический парсинг с использованием spaCy NER и custom regex-валидаторами.
- Нормализация таблиц с Camelot для сложных OCR-таблиц.
- Пакетная процессинга с многопоточностью через ThreadPoolExecutor.
- Активное обучение и дообучение на новых данных с модулем modAL.
- Логирование в файлы и консоль с уровнями DEBUG/INFO.
- Полная настройка через единый YAML-файл config.yaml.
- Вывод нормализованных данных и аналитики в JSON и CSV.

## Архитектура

```
core_parser/
├── config_manager/          # Загрузка и обработка конфигураций (ConfigManager)
├── pdf_extractor/           # Извлечение текста из PDF (PDFTextExtractor, OCR с кэшем)
├── classifier/              # Классификация документов (DocumentClassifier + BatchClassifier)
├── semantic_parser/         # Семантический парсинг полей (SemanticParser, FieldExtractors)
├── table_builder/           # Нормализация таблиц (TableBuilder)
├── batch_processor/         # Многопоточный пайплайн обработки (BatchProcessingPipeline)
├── learning_engine/         # ML обучение и active learning (LearningEngine)
├── web/                     # Веб-интерфейс управления на Eel (frontend)
├── ui/                      # Устаревший PyQt6 GUI (неиспользуется)
├── main.py                  # Точка входа, запуск Eel GUI
├── api.py                   # Планируемое FastAPI API (в разработке)
├── requirements.txt         # Список зависимостей
├── config.yaml              # Конфигурация системы
└── tests/                   # Юнит-тесты и интеграционные тесты
```

## Пайплайн Обработки

1. Загрузка конфигурации из YAML.
2. Извлечение текста и структурной информации из PDF (PDFTextExtractor с OCR).
3. Классификация документов ансамблем (правила, ML, BERT).
4. Семантический парсинг полей, извлечение таблиц и операций.
5. Анализ результатов, подсчет покрытий и точности.
6. Автоматические корректировки и рекомендации.
7. Сохранение резульатов в JSON и CSV.
8. Активное обучение с обратной связью пользователей для повышения качества.

Обработка происходит в многопоточном режиме с использованием ThreadPoolExecutor.

## Запуск

### Графический интерфейс на Eel

Запуск:

```bash
python main.py
```

- Запускает WEB GUI для управления загрузкой PDF, настройкой таблиц, запуском парсинга и просмотра результатов.
- Первый запуск скачивает модели EasyOCR и spaCy (до 60 секунд).
- Для упаковки с PyInstaller:  
  ```bash
  pyinstaller --add-data "easyocr_models;easyocr_models" --onefile main.py
  ```

### Программный запуск (без GUI)

Пример:

```python
from core_parser.config_manager.config_loader import ConfigManager
from core_parser.batch_processor.pipeline import BatchProcessingPipeline

config = ConfigManager()
pipeline = BatchProcessingPipeline(config, use_ocr=False, max_workers=4)
results = pipeline.process_folder('/path/to/pdfs')
```

На данный момент API не реализован, находится в стадии планирования.

## Конфигурация (config.yaml)

- Определяет сигнатуры документов и паттерны для полей.
- Позволяет добавлять новые типы документов.
- Поддерживает настройку валидации и правил.

## ML Классификация и Активное обучение

- Использует TfidfVectorizer и LogisticRegression для классификации.
- Активное обучение с modAL для подстройки модели на основе обратной связи.
- Частично поддерживается BERT (sentence-transformers) для улучшения качества.

## OCR и Кэширование

- EasyOCR с кэшированием результатов в SQLite.
- Используется только при необходимости (fallback).
- Значительно ускоряет повторную обработку.

## Логирование и Отладка

- Логи пишутся в `logs/debug.log` и выводятся в консоль.
- Уровни логирования: DEBUG, INFO.
- Логируются этапы пайплайна, ошибки и диагностические данные.

## Расширение Системы

- Добавление новых типов документов через конфигурацию и семантический парсер.
- Пользовательские паттерны и валидация в YAML.
- Расширение ML-моделей и активного обучения.

## Ограничения и Особенности

- Требуются PDF с текстом (не отсканированные без OCR).
- Поддержка русского языка и ориентированность на финансовые документы России.
- Не поддерживаются шифрованные PDF.
- Для работы OCR необходимо установить EasyOCR и при наличии GPU можно увеличить скорость.
