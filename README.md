# Core Parser: Система Парсинга Финансовых Документов (Версия 2.2)

## Описание

Core Parser — это полнофункциональная многофейзовая система для автоматического парсинга финансовых документов в формате PDF. Основная цель — автоматизация бухгалтерского учета предпринимателей с возможностью коммерциализации как SaaS или API.

Система включает:
- Извлечение текста из PDF и изображений (JPG, PNG, BMP, TIFF, WEBP) с поддержкой различных библиотек и fallback-логикой.
- **Интеллектуальную предобработку изображений** для улучшения качества OCR:
  - Автоматическое выравнивание документов (де-скью)
  - Улучшение контрастности (CLAHE)
  - Адаптивная бинаризация
  - Удаление шума
  - Улучшение резкости
  - Умное определение необходимости обработки
- Классификацию документов по 7 типам с использованием ансамбля методов (правила, ML, частично BERT):
  - Счет на оплату (invoice)
  - Платежное поручение (payment_order)
  - Акт (act)
  - Счет-фактура (invoice_factura)
  - Акт сверки (reconciliation_act)
  - Приказ об увольнении (dismissal_act)
  - Медицинский отчет (medical_report)
- Семантический анализ полей и нормализацию таблиц с умным разграничением заголовков и данных.
- Пакетную многопоточную обработку больших объемов документов.
- Высокоэффективное активное обучение с обратной связью для повышения качества.
- Оптимизированное кэширование OCR-результатов для повышения скорости.
- **Полностью русифицированный веб-интерфейс** на Eel для управления процессом и просмотра результатов:
  - Русские названия всех полей и типов документов
  - Автоматическая фильтрация пустых полей
  - Удобное отображение без технических префиксов
- Интеллектуальную валидацию данных и автоматику исправлений.
- Гибкую YAML-конфигурацию для паттернов и сигнатур.

## Основные возможности

- Поддержка извлечения текста через pdfplumber, PyMuPDF с использованием PaddleOCR при необходимости.
- **Обработка изображений**: поддержка JPG, PNG, BMP, TIFF, WEBP с автоматической предобработкой.
- **Предобработка изображений**: автоматическое улучшение качества для лучшего распознавания текста (работает офлайн, без интернета).
- Классификация на 7 типов документов: счет на оплату, платежное поручение, акт, счет-фактура, акт сверки, приказ об увольнении, медицинский отчет.
- Семантический парсинг с использованием spaCy NER и custom regex-валидаторами.
- **Умное извлечение полей из таблиц**: автоматическое различение заголовков таблиц и значений данных, фильтрация некорректных полей.
- Нормализация таблиц с Camelot для сложных OCR-таблиц.
- Пакетная процессинга с многопоточностью через ThreadPoolExecutor.
- Активное обучение и дообучение на новых данных с модулем modAL.
- Логирование в файлы и консоль с уровнями DEBUG/INFO.
- Полная настройка через единый YAML-файл config.yaml.
- Вывод нормализованных данных и аналитики в JSON и CSV.
- **Русифицированный интерфейс**: все названия полей, типы документов и элементы интерфейса на русском языке.

## Архитектура

```
core_parser/
├── config_manager/          # Загрузка и обработка конфигураций (ConfigManager)
├── pdf_extractor/           # Извлечение текста из PDF (PDFTextExtractor, OCR с кэшем)
├── classifier/              # Классификация документов (DocumentClassifier + BatchClassifier)
├── semantic_parser/         # Семантический парсинг полей (SemanticParser, FieldExtractors)
├── table_builder/           # Нормализация таблиц (TableBuilder)
├── batch_processor/         # Многопоточный пайплайн обработки (BatchProcessingPipeline)
├── learning_engine/         # ML обучение и active learning (LearningEngine)
├── web/                     # Веб-интерфейс управления на Eel (frontend)
├── ui/                      # Устаревший PyQt6 GUI (неиспользуется)
├── main.py                  # Точка входа, запуск Eel GUI
├── api.py                   # Планируемое FastAPI API (в разработке)
├── requirements.txt         # Список зависимостей
├── config.yaml              # Конфигурация системы
└── tests/                   # Юнит-тесты и интеграционные тесты
```

## Пайплайн Обработки

1. Загрузка конфигурации из YAML.
2. Извлечение текста и структурной информации из PDF (PDFTextExtractor с PaddleOCR при необходимости).
3. Предобработка изображений для улучшения качества OCR (если требуется).
4. Классификация документов ансамблем (правила, ML, BERT).
5. Семантический парсинг полей с умным разграничением заголовков и данных в таблицах.
6. Извлечение таблиц и операций с фильтрацией некорректных полей.
7. Анализ результатов, подсчет покрытий и точности.
8. Автоматические корректировки и рекомендации.
9. Сохранение результатов в JSON и CSV.
10. Активное обучение с обратной связью пользователей для повышения качества.

Обработка происходит в многопоточном режиме с использованием ThreadPoolExecutor.

### Особенности извлечения полей из таблиц

Система автоматически различает заголовки таблиц и значения данных:
- Фильтрует длинные текстовые значения (более 50 символов)
- Исключает реквизиты банков и длинные описания из списка полей
- Распознает стандартные заголовки таблиц (№, наименование, количество, цена и т.д.)
- Показывает только поля, найденные хотя бы в одном документе
- Убирает технические префиксы при отображении (например, `table_` не показывается пользователю)

## Запуск

### Графический интерфейс на Eel

Запуск:

```bash
python main.py
```

- Запускает полностью русифицированный WEB GUI для управления загрузкой PDF, настройкой таблиц, запуском парсинга и просмотра результатов.
- Интерфейс отображает все названия полей на русском языке (ИНН, КПП, Поставщик, Покупатель и т.д.).
- Автоматически скрывает поля, которые не найдены ни в одном документе.
- Первый запуск скачивает модели PaddleOCR и spaCy (до 60 секунд).
- Для упаковки с PyInstaller:  
  ```bash
  pyinstaller --add-data "core_parser;core_parser" --add-data "web;web" --onefile main.py
  ```

### Программный запуск (без GUI)

Пример:

```python
from core_parser.config_manager.config_loader import ConfigManager
from core_parser.batch_processor.pipeline import BatchProcessingPipeline

config = ConfigManager()
pipeline = BatchProcessingPipeline(config, use_ocr=False, max_workers=4)
results = pipeline.process_folder('/path/to/pdfs')
```

## Конфигурация (config.yaml)

- Определяет сигнатуры документов и паттерны для полей.
- Позволяет добавлять новые типы документов.
- Поддерживает настройку валидации и правил.

## ML Классификация и Активное обучение

- Использует TfidfVectorizer и LogisticRegression для классификации.
- Активное обучение с modAL для подстройки модели на основе обратной связи.
- Частично поддерживается BERT (sentence-transformers) для улучшения качества.

## OCR и Кэширование

- PaddleOCR с кэшированием результатов в SQLite.
- Используется только при необходимости (fallback, когда извлеченный текст слишком короткий).
- Значительно ускоряет повторную обработку.
- Поддержка русского языка из коробки.

## Логирование и Отладка

- Логи пишутся в `logs/debug.log` и выводятся в консоль.
- Уровни логирования: DEBUG, INFO.
- Логируются этапы пайплайна, ошибки и диагностические данные.

## Ограничения и Особенности

- Система автоматически использует OCR для документов с недостаточным количеством текста.
- Полная поддержка русского языка и ориентированность на финансовые документы России.
- Поддержка медицинских отчетов и лабораторных анализов.
- Не поддерживаются шифрованные PDF.
- Для работы OCR необходимо установить PaddleOCR (устанавливается автоматически при установке зависимостей).
- При наличии GPU можно ускорить обработку, изменив настройки в config.yaml.
- Интерфейс полностью на русском языке для удобства русскоязычных пользователей.
